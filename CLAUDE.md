# CLAUDE.md — The Still Got It Collective

Cleveland's retro dance party event site. Hosted on **GitHub Pages** at
`https://www.stillgotitcollective.com`. Backend is a **Cloudflare Worker** with
a D1 (SQLite) database. Content is managed via JSON files and Decap CMS.

---

## Deployment

**Static site** deploys automatically on every push to `main` via GitHub Actions
(`.github/workflows/pages.yml`). No build step — files are served as-is.

The Stripe publishable key is injected at build time from the GitHub Actions
secret `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY`. **Do not commit
`assets/js/stripe-publishable.js`** — it is generated by CI.

**Cloudflare Worker** is deployed separately:
```bash
cd workers/merch-backend
wrangler deploy
```
Worker secrets (`STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, `PRINTFUL_TOKEN`)
are set via Cloudflare Dashboard or `wrangler secret put <NAME>` — never in
`wrangler.toml` or committed files.

## Common Maintenance Tasks

### Update the next event (banner + tickets section + event card)

Three places need to stay in sync:

1. **`content/site.json`** — `banner` object (announcement bar at top of page)
   and `tickets` object (ticketing URL, body text, label).
2. **`content/site.json`** — `hero.ctaPrimaryUrl` if the hero CTA points to tickets.
3. **`data/events.json`** — add a new entry to the `events` array. Keep past
   events in the array; the frontend filters by date.

Event entry shape:
```json
{
  "id": "still-got-it-vol-4",
  "title": "Event Title",
  "date": "2026-04-01",
  "time": "6PM",
  "location": "B-Side Lounge, Cleveland",
  "venue": "",
  "description": "Short description.",
  "image": "/assets/images/uploads/gallery/thumb/<thumb>.webp",
  "ticketUrl": "https://ticketscandy.com/...",
  "ctaLabel": "Get Tickets"
}
```

### Add a "Latest Updates" card

Edit `content/updates.json`. Each card:
```json
{
  "title": "Card headline",
  "body": "Body copy.",
  "date": "2026-04-01",
  "pinned": false,
  "ctaLabel": "Button label",
  "ctaUrl": "https://...",
  "ctaStyle": "primary",
  "imageUpload": "/assets/images/uploads/<filename>",
  "alt": "Image alt text"
}
```
Set `"pinned": true` to force a card to the top of the list.

### Add photos to the gallery

1. Drop originals into `assets/images/_incoming_raw/`.
2. Run the image processor (requires `npm install` once):
   ```bash
   npm run images:build
   ```
   This generates WebP thumbs and full-size variants under
   `assets/images/uploads/gallery/` and updates `manifest.json`.
3. Add entries to `content/gallery.json`:
   ```json
   {
     "src": "/assets/images/uploads/gallery/full/<hash>-full.webp",
     "thumb": "/assets/images/uploads/gallery/thumb/<hash>-thumb.webp",
     "alt": "Description of the photo",
     "featured": false
   }
   ```
   Set `"featured": true` to surface the photo on the first page of the gallery.
4. Commit both the new image files and the updated JSON.

You can also trigger image processing via GitHub Actions:
**Actions → Process incoming images → Run workflow.**

### Update merch products

`content/merch.json` is the product catalog served to the frontend.
Products fulfilled via Printful are synced daily at 2 AM UTC by the Worker
cron job, or manually:
```bash
# Trigger a sync (requires SYNC_SECRET_TOKEN if set)
curl -X POST https://www.stillgotitcollective.com/api/sync/products \
  -H "Authorization: Bearer <SYNC_SECRET_TOKEN>"
```
For manual edits, each product needs at minimum:
`id`, `name`, `priceCents`, `image`, and a `fulfillment` block.

### Update footer / social links

Edit `content/site.json` → `footer.socialLinks` array.

## Content Style Notes

- **Tone:** Warm, irreverent, nostalgic. The brand voice is upbeat and slightly
  self-aware — "Maximum fun. Reasonable bedtime."
- **Dates:** Display format is `Mon, Month DD, YYYY • H–H PM` (e.g., `Wed, Feb 26, 2026 • 6–10 PM`).
- **Location:** Always use `B-Side Lounge, Cleveland` for the standard venue.

## Architecture Overview

```
GitHub Pages (static)
  index.html               ← main site
  merch/                   ← storefront + checkout
  assets/css/style.css     ← design tokens + all global styles
  assets/js/scripts.js     ← gallery, events, lightbox, toasts
  assets/js/merch.js       ← product grid, cart, abandoned cart
  assets/js/checkout.js    ← Stripe Payment Element flow
  content/*.json           ← CMS-managed content
  data/events.json         ← event calendar

Cloudflare Worker (sgic-merch-api)
  POST /api/checkout           ← create PaymentIntent + order row
  POST /api/stripe/webhook     ← mark paid, trigger Printful
  GET  /api/products           ← serve product catalog
  GET  /api/orders/:id         ← order status (success page)
  POST /api/carts/abandoned    ← save abandoned cart
  GET/POST /api/carts/recover/:token
  POST /api/sync/products      ← manual Printful sync
  Cron: daily Printful sync @ 2 AM UTC

Cloudflare D1 (sgic-merch)
  orders / order_items / order_events
  abandoned_carts
```

## Known Issues / Open Items

- **Toast notifications** are implemented (`window.showToast`) but not yet
  wired into the merch/checkout JS flows.
- **Dark mode** CSS exists (`prefers-color-scheme: dark` in `style.css`) but
  there is no toggle UI.
- **Abandoned cart recovery** lacks server-side expiration and rate limiting.
